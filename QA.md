# Проверка прототипа — 29.10.2026

Проверялась публичная версия https://sinyuta49.github.io/supplier-scout/ и повторяемый браузерный сценарий на локальной сборке.

## Пройдено

- Поиск: молоко / Петербург, упаковка / Екатеринбург, рыба / Москва, стаканы / Екатеринбург.
- Фильтр конкретного региона исключает компании, для которых заявлена только доставка по РФ.
- Фильтр сведений о документах не включает карточки с неизвестными документами.
- Сравнение FoodFace и U2B: минимальная партия отделена от порога бесплатной доставки.
- Ссылки на источники и контакты показаны в карточках. Условия U2B сверены с официальной страницей.
- Список и заметка сохраняются после перезагрузки.
- CSV действительно скачивается: UTF-8 BOM, 11 столбцов, данные и ссылки на источники.
- Несуществующий запрос показывает пустое состояние.
- Мобильная версия не имеет горизонтального переполнения.
- В браузерных сценариях не возникло ошибок JavaScript.
- В статическом режиме нет сетевых обращений к chatgpt.site.

## Найдено и исправлено

1. Запрос «сырники» выбирал молочную категорию из-за совпадения с коротким корнем «сыр». Теперь используется более специфичное совпадение и категория готовой продукции.
2. «Упаковка для доставки» ошибочно сужала выдачу до описаний с точным словом «доставки». Служебное уточнение больше не отсекает подходящие карточки категории.

## Границы проверки и продукта

Проверка не подтверждает надёжность поставщиков, остатки, актуальность всех коммерческих условий или наличие конкретного SKU. Поиск категорий — подбор возможных поставщиков, не гарантия наличия товара. Каталог ограничен 13 компаниями. GitHub Pages не запускает серверный сбор и не обнаруживает новых поставщиков. Эти ограничения указаны в интерфейсе и README.
