Что уже работает

Поиск по категориям, товарным словам и регионам, сравнение до четырёх компаний, список для связи, личные заметки, запрос коммерческого предложения и экспорт CSV. Сервер умеет заново прочитать публичную страницу поставщика и показать найденные контакты и фрагменты условий с источником.

Откуда данные

Стартовый каталог собран с официальных сайтов 13 компаний 29 октября 2026 года. Это ограниченная подборка, а не поиск по всему интернету. Наличие филиала отличается от обещания доставки по России: такие компании отмечены отдельно. Заметки и списки сохраняются только в вашем браузере.

Чего мы не утверждаем

Мы не проверяем надёжность бизнеса, актуальное наличие и подлинность сертификатов. Упоминание документов на сайте — не проверка документов. Порог бесплатной доставки — не минимальный заказ. Отсутствие цены не значит, что поставщик дорогой.

Как устроено сравнение

Сначала учитываются город и категория, затем полнота опубликованных сведений. Это не рейтинг надёжности и не оценка качества. В сравнении видны факты, пробелы и вопросы, которые стоит задать перед закупкой.

Следующий этап

Подключить лицензированный поисковый API для обнаружения новых компаний, затем извлечение структурированных фактов через LLM с обязательными цитатами, проверкой схемы и подтверждением человеком. Добавить хранение истории и регулярное обновление. В этом прототипе нет скрытых платных API и имитации работы ИИ.
